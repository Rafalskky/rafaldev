# Work strip is public artifacts, not employment

The Work strip only shows Projects: work with a live site or a repository the visitor can open. Jobs (Brixo, Marknadsinformation, and similar) stay on About as employment history. Putting employer chapters on an image-led strip without a public artifact would pad the Portfolio and break the Obys-rich rule that you look at the work, not a job title. Job Hunter is the exception that proves the rule: no website, so the artifact is GitHub and the image is a designed poster, not invented UI.
