# Keep the Obys-rich visual language

This Portfolio started as a friend's brief and is now Rafal's own site. We keep the existing Obys-inspired shell (large type, image-led Work strip, motion, sparse chrome) instead of switching to a conventional CV layout, because the site has to *look* like frontend craft, not only list it.

Craft references are Obys Agency and yulia.world (an Obys-built fashion site). We take scale, image-led scroll, sparse chrome, the split-Mark mechanic, and a 50/50 case view for a Project. We do not copy Yulia's numbered fashion IA, couture photography, Obys' studio case-study index, or their center glyph. The Mark is an original geometric split, not letters, not theirs. Friend identity, leftover game-dev assets, and padded copy are replaced; the visual system stays.
